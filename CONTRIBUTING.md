# Contributing

Contributions are welcome when they make the method easier to understand, verify, or reuse.

## Good contributions

- clearer templates and fictional examples;
- better ways to verify links, sources, state, or acceptance evidence;
- privacy-safe adapters for other local-first knowledge tools;
- translations that preserve the distinction between evidence, inference, and recommendation.

## Pull request checklist

- [ ] No real private data or credentials.
- [ ] Product claims link to official public documentation.
- [ ] No duplicate canonical document was created.
- [ ] Relative links resolve.
- [ ] `python3 scripts/privacy_scan.py .` passes.
- [ ] `python3 -m unittest discover -s tests -v` passes.

Please explain the problem, the change, and how you verified it.

# 来源与结论评估

## 来源可靠性

| 等级 | 含义 | 使用方式 |
|---|---|---|
| A | 原文、原始数据、官方发布或可回查一手证据 | 可作主证据，仍需检查时效和范围 |
| B | 权威二手资料，或能定位一手证据的复盘 | 可支撑工作判断，关键数字和引语回查一手源 |
| C | 一般二手内容、模型总结、证据链不完整的内部实践 | 只作方向或待验证假设 |
| D | 来源缺失、不可访问或转述对象不明 | 不得当作已核实事实 |

## 结论置信度

| 等级 | 含义 | 推荐表达 |
|---|---|---|
| A | 直接证据支持，关键反例已处理 | 在当前边界内已确认 |
| B | 核心方向有支持，仍有外推或待验证环节 | 当前较支持，条件是…… |
| C | 合理解释，证据仍不足 | 待验证假设 |
| D | 与证据冲突或缺少关键前提 | 当前不支持 / 需要重做 |
